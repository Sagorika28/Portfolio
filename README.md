# Portfolio Website Template

A premium dark-themed portfolio website built with vanilla HTML, CSS, and JavaScript. No frameworks required.

## Features

- 🎨 Modern dark theme with glassmorphism effects
- ⌨️ Typing animation in hero section
- 📜 Scroll-reveal animations & parallax effects
- 🤖 Built-in chatbot widget (rule-based NLP)
- 📱 Fully responsive (desktop, tablet, mobile)
- 🔍 SEO-ready with meta tags & Open Graph
- 🎯 Spotlight hover effects on project cards

## Getting Started

1. Replace placeholder content in `index.html` with your details
2. Add your images to the `images/` folder (profile photo as `profile.jpg`)
3. Add your resume/CV to the `resume/` folder as `resume.pdf`
4. Add project screenshots/videos to the `assets/` folder
5. Update the chatbot knowledge base in `script.js` (line ~428)
6. Replace the Google Analytics ID in `index.html` (line ~8)
7. Open `index.html` in your browser — done!

## Structure

```
├── index.html          # Main HTML file
├── style.css           # All styles (2700+ lines)
├── script.js           # Animations, chatbot, interactions
├── assets/             # Project images, videos, SVGs
├── images/             # Profile photos
└── resume/             # Resume PDF, transcripts
```

## Customization

- **Colors**: Edit CSS variables in `:root` at the top of `style.css`
- **Fonts**: Change Google Fonts link in `index.html` `<head>`
- **Sections**: Add/remove sections in `index.html`, update nav links
- **Chatbot**: Edit the `knowledgeBase` object in `script.js`

## Deployment

Host for free on [GitHub Pages](https://pages.github.com/):
1. Create a repo named `yourusername.github.io`
2. Push these files to the repo
3. Your site will be live at `https://yourusername.github.io`
